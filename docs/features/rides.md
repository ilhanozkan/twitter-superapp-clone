# Rides

Ships in the `rides` PR, which describes the feature here: quotes, booking a
driver, the schematic map, trip progress, cancelling and refunds, and tipping
the driver; where it lives in the app; its empty, loading, error and read-only
states; its limits; and how to try it with the demo data. Until then the
feature is off: its navigation, tiles and buttons are hidden and its pages
answer 404.

How SuperApp features are built is in [docs/SUPERAPP.md](../SUPERAPP.md); the
API is in [docs/api/rides.md](../api/rides.md).
