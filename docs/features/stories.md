# Stories

Ships in the `stories` PR, which describes the feature here: the story tray on
Home, the viewer, the composer, viewers and replies; where it lives in the
app; its empty, loading, error and read-only states; its limits; and how to
try it with the demo data. Until then the feature is off: its navigation,
tiles and buttons are hidden and its pages answer 404.

How SuperApp features are built is in [docs/SUPERAPP.md](../SUPERAPP.md); the
API is in [docs/api/stories.md](../api/stories.md).
