# Orders

Ships in the `orders` PR, which describes the feature here: ordering from a
Tweet or a menu, tracking, cancelling and refunds, and the Business board;
where it lives in the app; its empty, loading, error and read-only states; its
limits; and how to try it with the demo data. Until then the feature is off:
its navigation, tiles and buttons are hidden and its pages answer 404.

How SuperApp features are built is in [docs/SUPERAPP.md](../SUPERAPP.md); the
API is in [docs/api/orders.md](../api/orders.md).
